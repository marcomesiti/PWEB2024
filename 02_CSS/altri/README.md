 Esercizi CSS
 =======
 
 
 01- Posizionamento di un DIV:
	1. Definire un div 200px x 200px e sfondo rosso
	2. Posizionare il div al centro (verticalmente) della pagina
	Nota: valutare l'uso di un secondo div contenitore di tutta la pagina

[Soluzioni](https://github.com/SaraBonfitto/PWEB_23_24/tree/main/02_CSS/lezione/altro/soluzioni/01)

02- Posizionamento di un DIV responsive:
	1. Creare un div contenente del testo a piacere
	2. Centrare un div verticalmente in modo che sia responsive (ridimensionando la pagina rimane al centro)
	Nota: non si conosce la dimensione del div contenente il testo ma si conosce la dimensione del container principale 
	che è 1024px x 640px
	

03 - Uso del CSS per visualizzare una pagina HTML:
	1. considera la pagina page.html. Visualizzala con un browser. 
	2. Controlla il tipo di tag che sono presenti. Se non li conosci, cerca sul w3c il loro significato
	3. Considera adesso il foglio di stile style1.css (che si trova nella cartella "css")
	4. Includi il file in page.html
	5. Visualizza nuovamente il file page.html con un browser
	6. Esamina le regole che sono presenti in style1.css
	7. prova a cambiare qualche coppia <proprietà, valore> per cambiare lo stile della pagina

04 - Uso di diversi CSS per visualizzare la stessa pagina HTML:
	1. Considera la pagina page.html. Nella pagina sono stati inclusi diversi CSS che possono essere attivati attraverso i bottoni nell'header della pagina (l'attivazione viene fatta
	attraverso javascript... ma per ora non preoccupartene).
	2. Prova a vedere quali effetti diversi si possono ottenere a partire dalla stessa pagina.
	3. Controlla i vari CSS che sono stati inseriti (se ci sono regole che non conosci, prova a cercarle sul W3C)
